# Разработка набора Ralph Kit в Claude Code

Правила лежат в `AGENTS.md` и импортируются ниже, чтобы Codex и Claude Code
читали один источник. Новое правило пишут туда, а не сюда; здесь только то, что

@AGENTS.md

## Чем `.claude/` этого репозитория отличается от рабочего

`.claude/agents/**` и `.claude/skills/**` здесь — поставляемая часть набора, а не
инструменты разработки набора. Их правка меняет поведение сессий у каждого
потребителя, поэтому она такая же правка продукта, как изменение кода цикла:
с тестом, записью в `CHANGELOG.md` и номером версии.

Скилла для разработки самого набора здесь нет намеренно: каталог `.claude/`
копируют в чужой проект целиком, и такой скилл уехал бы к потребителю мусором.
Порядок разбора правок держат в `AGENTS.md`.
