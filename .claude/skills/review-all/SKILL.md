# Полное ревью изменений

Запусти через инструмент Task три субагента параллельно:

1. `security-reviewer` — безопасность изменений.
2. `performance-reviewer` — производительность.
3. `test-coverage-reviewer` — покрытие тестами.

Собери ответы в один отчёт: раздел на каждого субагента, внутри — его находки
без пересказа.
