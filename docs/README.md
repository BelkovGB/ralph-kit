# Документы репозитория набора

Каталог `docs/` в проект-потребитель не копируется: здесь материалы разработки
самого набора.

- `tips.md` — колонка подсказок: приёмы, от которых набор проще поставить и
  использовать, вместе с примерами для конкретных стеков. Всё, что относится к
  инструментам чужого проекта, а не к поведению Ralph, живёт здесь.
- `archive/` — документы отложенной работы. Требования в них не отменены, но
  работа не ведётся; при возврате их сверяют с текущим кодом.
